## 0.0.0-beta.1 — Initial Beta Release

This is the first public release of **Player Activity View**, a complete ground-up rewrite and modernization of the original WATUT mod for Minecraft 1.21 / NeoForge 26.1.2.

### What's Included

- **Player status detection** — typing, GUI interaction, and idle states
- **34 particle textures** for different GUI types, chat states, and idle indicators
- **Custom particle engine** rendering above player heads
- **Idle detection** with visual indicators in the tab list and above heads
- **"Player is typing..."** chat overlay
- **Arm pointing and clicking animations** driven by mouse position
- **Item transfer particles** between players and containers
- **Three-tier config system** (Common, Client, Server-synced)
- **Server-synced settings** — admins control what's visible
- **Privacy controls** — players can opt out of detailed GUI sharing
- **Custom arm correction system** via JSON config
- **Sound effects** for GUI opens and mouse clicks

### Notes

- This is a beta release. Some features from the original mod (dynamic screen capture, full mixin-based animations) are being updated to work with Minecraft 26.1.2's changed rendering API
- Requires NeoForge 26.1.2.78+
- No external dependencies required
