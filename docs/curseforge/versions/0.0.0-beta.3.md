<h2>v0.0.0-beta.3 — Screen mirror update fixes</h2>

<h3>Fix</h3>
<ul>
<li><strong>Screen mirror / GUI visualizer not updating</strong>: the client ticked <code>tickGame()</code> before
  <code>tickPlayerClient()</code>, so <code>playerGuiState</code> was still <code>NONE</code> when the capture condition was
  evaluated — <code>canRenderNewGUI</code> was true but <code>validGui</code> was false on the frame the GUI opened, and
  by the next tick <code>lastScreen == screen</code> blocked it. The screen capture only happened once per session.
  Reordered the client tick so <code>tickPlayerClient</code> runs before <code>tickGame</code>, restoring live screen
  mirror updates.</li>
<li><strong>NPE on chunked screen packets</strong>: the receiver now tolerates out-of-order chunks
  (<code>packetIndex=1</code> before <code>packetIndex=0</code>) instead of throwing.</li>
</ul>
