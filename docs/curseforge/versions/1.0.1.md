<h2>v1.0.1 — Chat hands animation fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Chat hands now raise when the chat opens</strong>: the typing pose (arms raised toward the screen, alternating anti-phase sway so one arm rises while the other falls) previously only triggered on <code>CHAT_TYPING</code>. Since opening the chat reports <code>CHAT_FOCUSED</code> (text box focused, nothing typed yet), the arms stayed down. The pose now applies to any typing GUI (<code>CHAT_SCREEN</code>, <code>EDIT_BOOK</code>, <code>EDIT_SIGN</code>, <code>COMMAND_BLOCK</code>) with a chat state other than <code>NONE</code>, so the "writing" animation plays from the moment the screen opens.</li>
</ul>
