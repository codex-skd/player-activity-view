<h2>v0.0.0-beta.12 — Live screen mirror reimplemented</h2>

<h3>Fix</h3>
<ul>
<li><strong>Screen mirror was not rendering</strong>: the feature that shows other players a live preview of your inventory/menu screen on your in-game model was left as a stub when the mod was ported to this Minecraft version, so it never captured or displayed anything.</li>
<li><strong>Network payload corruption bug</strong>: a packet field carried the compressed byte count instead of the decompressed size, which would have corrupted the screen image as soon as capture worked again.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>New capture pipeline: grabs the main render target via <code>Screenshot.takeScreenshot</code> on <code>RenderFrameEvent.Post</code>, downscales, compresses and sends it.</li>
<li>New <code>DynamicScreenRenderer</code>: draws the received screen as a camera-facing world-space billboard via <code>SubmitCustomGeometryEvent</code>, replacing the old particle-based approach which is no longer capable of arbitrary per-instance textures in this version.</li>
</ul>

<h3>Notes</h3>
<blockquote>This is a beta release. The screen mirror rendering has been verified to compile and build cleanly against this Minecraft version's APIs, but has not yet been visually verified in-game — please report sizing/positioning issues.</blockquote>
