<h2>v0.0.0-beta.17 — Fix single-packet screen data size bug</h2>

<h3>Fix</h3>
<ul>
<li><strong>Screen mirror still not showing</strong>: the network message's declared decompressed size was wrong for small (single-packet) captures — which became the common case once cropping was added in beta.15 — so the receiver always rejected the data before building the texture. Fixed the leftover instance of this bug.</li>
</ul>

<h3>Notes</h3>
<blockquote>This build also adds debug logging to the capture/send/receive/render pipeline, so if something is still off, sharing <code>latest.log</code> will point straight at it.</blockquote>
