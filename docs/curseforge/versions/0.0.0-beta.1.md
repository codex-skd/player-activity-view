<h2>v0.0.0-beta.1 — First Fabric port for Minecraft 26.2</h2>

<h3>Port</h3>
<ul>
<li><strong>First Fabric release</strong>: full port of the NeoForge 26.2 build (which itself is the complete feature set of the stable 26.1.2 v1.0.0) to Minecraft 26.2 / Fabric API 0.156.0. Requires Fabric Loader 0.19.3+.</li>
<li><strong>Same feature set</strong>: typing indicators, GUI visualizer, live screen mirror, idle detection, inventory animations, arm animations, privacy controls and server-synced config.</li>
<li><strong>Networking</strong>: reimplemented on Fabric <code>PayloadTypeRegistry</code> + <code>ClientPlayNetworking</code>/<code>ServerPlayNetworking</code>, sharing the same custom payload records as the NeoForge build.</li>
<li><strong>Config</strong>: the NeoForge <code>ModConfigSpec</code> was replaced by a JSON-backed equivalent (<code>player_activity_view-common/client/server.json</code> in the config dir) with the same keys, so settings migrate cleanly.</li>
<li><strong>Rendering</strong>: the live screen mirror billboard now hooks Fabric <code>LevelRenderEvents.COLLECT_SUBMITS</code> (NeoForge's <code>SubmitCustomGeometryEvent</code> equivalent).</li>
</ul>
