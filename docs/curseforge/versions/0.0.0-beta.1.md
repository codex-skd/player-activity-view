<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Player Activity View for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. Same feature set as the 26.1.2 / 26.2 builds &mdash; typing indicators, GUI visualizer, live screen mirror, idle detection, inventory animations, arm animations, privacy controls and server-synced config &mdash; running on the 1.21.1 client API.</p>

<h3>About this build</h3>
<ul>
<li><strong>Back-port from the 26.1.2 line</strong>, using the upstream <a href="https://www.curseforge.com/minecraft/mc-mods/what-are-they-up-to">WATUT</a> 1.21.0 sources by <em>Corosus</em> as the reference for the 1.21.1 render API. Keeps the independent, CoroUtil-free codebase and every fix from the 21 betas of the 26.1.2 release.</li>
<li>The 1.21.2+ render-state extraction layer is replaced by the 1.21.1 mixin approach: <code>Gui.render</code>, <code>Screen.renderWithTooltip</code>, <code>Screen.renderBackground</code>, <code>PlayerModel.setupAnim</code>, <code>GameRenderer.reloadShaders</code>. The screen mirror renders through a custom particle engine, as in upstream.</li>
</ul>

<h3>Technical</h3>
<ul>
<li>Java 21 toolchain; mixin <code>compatibilityLevel</code> <code>JAVA_21</code>.</li>
<li><code>ResourceLocation</code> (was <code>Identifier</code>), <code>PacketDistributor</code> (was <code>ClientPacketDistributor</code>), <code>FMLEnvironment.dist</code>, <code>CompoundTag</code> direct getters; <code>ShaderInstanceBlur</code> restored as a real <code>ShaderInstance</code> subclass loading namespaced blur shaders.</li>
<li><code>accesstransformer.cfg</code> uses official (Mojang) member names.</li>
<li>Early-startup safety: the server-synced config is read through <code>isLoaded()</code>-guarded accessors so the first shader reload (before configs load) no longer throws; the particle renderer re-initialises once the config is available.</li>
</ul>

<h3>Notes</h3>
<blockquote>Beta. Loading, all mixins and the custom blur shaders are verified in a clean 1.21.1 / NeoForge 21.1.249 client. In-game behaviour with another player, and loading alongside a shader pack (Iris / Oculus), are not yet verified &mdash; please report issues. Install on both client and server; every feature is toggleable client-side and via the server config.</blockquote>
