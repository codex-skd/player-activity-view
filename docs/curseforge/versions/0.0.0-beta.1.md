<h2>v0.0.0-beta.1 — Port to Minecraft 26.2</h2>

<h3>Port</h3>
<ul>
<li><strong>Full port to 26.2</strong>: ported from the <code>26.1.2</code> branch (v1.0.0) to Minecraft 26.2 / NeoForge 26.2.0.32-beta.</li>

<li><strong>Updated skeleton</strong>: moddev plugin 2.0.142, build metadata for 26.2.</li>
<li>Includes the complete feature set of the stable 26.1.2 release: typing indicators, GUI visualizer, live screen mirror, idle detection, inventory animations, arm animations, privacy controls and server-synced config.</li>
