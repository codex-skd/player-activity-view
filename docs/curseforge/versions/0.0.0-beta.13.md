<h2>v0.0.0-beta.13 — Fix startup crash from beta.12</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crash on launch / at the main menu</strong>: <code>beta.12</code>'s new screen-capture hook read a server-synced config option before checking whether the player was actually in a world, which crashed with <code>IllegalStateException: Cannot get config value before config is loaded</code> as soon as the client started rendering.</li>
</ul>

<h3>Notes</h3>
<blockquote>If you installed beta.12, update to this version — beta.12 crashes on startup.</blockquote>
