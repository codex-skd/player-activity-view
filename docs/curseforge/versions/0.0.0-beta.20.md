<h2>v0.0.0-beta.20 — Screen mirror crop fixes for survival inventory and chat</h2>

<h3>Fix</h3>
<ul>
<li><strong>Survival inventory crop collapses</strong>: the mirrored crop was computed purely from whatever GUI elements the screen happened to extract, and empty slots (no item and no placeholder sprite) contribute no bounds, so the crop's right/bottom edges shrank depending on what the player had in their inventory. The creative palette is always full of items so it was unaffected — same function, different screen contents, different result. The crop now unions the deterministic panel rectangle (<code>leftPos</code>/<code>topPos</code>/<code>imageWidth</code>/<code>imageHeight</code>) for every container screen, so the full panel is always captured regardless of inventory contents, active potion effects or recipe book state.</li>
<li><strong>Chat mirror captures the whole scrollback</strong>: the generic element bounding box spanned the full-width message log (most of the screen height), making the mirrored content tiny and illegible once squeezed into the small panel. ChatScreen now gets a dedicated crop anchored at the text input field plus the four most recent message lines, matching where vanilla chat actually renders the input and the message log.</li>
</ul>
