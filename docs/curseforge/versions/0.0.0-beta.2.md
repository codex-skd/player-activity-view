<h2>v0.0.0-beta.2 — Networking fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Kick on join / ClassCastException</strong>: the payload types were never registered — only the
  networking instance was constructed, so the server dispatched <code>nbt_client</code> as
  <code>DiscardedPayload</code> and kicked players on join. Payload types now register in
  <code>onInitialize</code>, and the clientbound receiver registers directly in
  <code>PlayerActivityClient.onInitializeClient()</code>.</li>
</ul>
