<h2>v0.0.0-beta.19 — Screen mirror fixes and typing animation</h2>

<h3>Fix</h3>
<ul>
<li><strong>Own player sees own mirror</strong>: the local player no longer sees their own screen mirror preview — being able to see your own GUI mirrored in front of you while you are already interacting with it was useless and awkward. The 3rd-person exemption that allowed it has been removed.</li>
<li><strong>Chat screen mirror oversized</strong>: the crop bounding-box included the full-width message history area, producing an extreme aspect ratio that made the 3D panel blow up in size. The effective aspect ratio is now clamped and the panel half-dimension is capped.</li>
<li><strong>Inventory screen crop cut off</strong>: <code>computeGuiPanelBounds</code> only iterated <code>forEachElement</code> (blit/glyph render states), missing item slots, text labels, and the player model picture-in-picture preview. All four element types are now included for a complete bounding box.</li>
<li><strong>Typing hand animation</strong>: the typing pose is now animated with a sine wave, alternating the arms up and down over time for a natural typing look instead of a static hand position.</li>
</ul>
