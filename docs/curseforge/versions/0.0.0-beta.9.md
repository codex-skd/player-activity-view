<h2>v0.0.0-beta.9 — Particle rendering fix and arm animation simplification</h2>

<h3>Fix</h3>
<ul>
<li><strong>Particles not visible</strong>: Custom particle engine replaced with vanilla <code>ParticleEngine</code>. Particles are now rendered through the standard particle pipeline instead of a custom engine with empty <code>render()</code> method.</li>
<li><strong>Weird arm animations</strong>: Simplified <code>onSetupAnim</code> to directly compute rotations based on player status instead of relying on the lerp system. Rotations are now applied directly without the complex <code>setPoseTarget</code>-&gt;lerp pipeline.</li>
</ul>

<h3>Removed</h3>
<ul>
<li><code>ParticleEngineCustom</code> — replaced by vanilla <code>ParticleEngine</code></li>
<li><code>ParticleEngineMixin</code> — no longer needed</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>onSetupAnim(HumanoidModel, HumanoidRenderState)</code> now checks <code>PlayerGuiState</code>, <code>PlayerChatState</code>, and idle status directly</li>
<li>No lerp system needed — rotation targets computed per-frame</li>
</ul>
