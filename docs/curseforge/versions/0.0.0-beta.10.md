<h2>v0.0.0-beta.10 — Critical crash fix: null sprite in particle rendering</h2>

<h3>Fix</h3>
<ul>
<li><strong>Crash when player joined</strong>: <code>NullPointerException</code> in <code>ParticleRotating.extractRotatedQuadForParticle()</code> caused by null sprite. Added null-safety check before rendering.</li>
</ul>

</ul>
